# Cercaveicoli Import

Programma per cercare auto usate in Germania, Belgio, Francia e Spagna da un'unica pagina.

**Per installarlo su un PC:** scarica [Cercaveicoli.zip](https://github.com/Marco112344/cercaveicoli/raw/main/Cercaveicoli.zip), estrai la cartella e fai doppio clic su `Avvia.bat` (Windows) o `avvia.command` (Mac). Le istruzioni sono in `LEGGIMI.txt`.

Una volta installato si aggiorna da solo: a ogni avvio controlla `versione.json` in questa pagina e, se c'è una versione nuova, la scarica, la controlla e la installa.

In questi file non c'è nessuna chiave né password: le impostazioni di ogni PC restano su quel PC.
